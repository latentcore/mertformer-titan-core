# Project Summary

MertFormer Titan is an offline-first, auditable AI systems repository centered on three connected surfaces: low-bit systems and runtime infrastructure, offline assistant and RAG foundations, and a contained chess proof-and-teaching lane used to demonstrate evaluation discipline. The repo is currently a pilot-ready pre-training baseline rather than a finished trained-model release.

The strongest signals are not headline benchmark claims. The strongest signals are a train-readiness contract that currently reports `TRAIN_ALLOWED` with `READY_REMOTE_BOOTSTRAP`, an active recommended start lane of `remote_bootstrap`, an explicit measured-versus-unmeasured claim boundary, a multi-backend low-bit path with explicit fallback semantics, and a product direction that treats local retrieval, tool governance, and observability as real system components.

The best application framing is not "already proven frontier scaling scientist." The better and more defensible framing is "systems-focused research engineer who cares about turning compute into trustworthy signal."

The major open class is post-run evidence: a real owned training run, trained checkpoints, checkpoint-bound benchmarks, a trained demo bundle, and trained export or device measurements. The repo is designed to make that boundary explicit rather than narrate it away.
