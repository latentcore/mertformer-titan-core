# Contributing

This repository is proprietary and currently **not open to external contributions**.

## Internal Contribution Flow
- Use branches with the `codex/` prefix.
- Keep all claims and metrics aligned with **pre-training / pending validation** status.
- Avoid committing large binaries or datasets; prefer scripts and reproducible configs.
- Document changes briefly in the relevant README/MD when they affect user-facing behavior.

## Security
If you discover a security issue, do not open a public issue. Contact the project owner directly.
