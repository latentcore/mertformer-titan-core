# Benchmarks Outputs

This folder stores benchmark generation outputs and summaries. Unless otherwise noted,
files here are **pre-training** and must be regenerated after a full training run.

## Files
- `humaneval_outputs.jsonl` and `mbpp_outputs.jsonl`
  Generated by: `python scripts/benchmarks_internal.py --run`
- `gsm8k_outputs.jsonl` and `gsm8k_summary.json`
  Generated by: `python eval/gsm8k.py --run` (or `--score-only` for summary)
- `smoke_train_metrics.json`
  Generated by: `python scripts/smoke_train_benchmark.py` (docs-only smoke; synthetic tokens)
- `summary.json`
  Generated by: `python eval/report_builder.py`
- `math_fastproof/`
  Canonical math-fastproof artifacts (see subfolder README).
- `text_understanding/`
  Text-understanding PoC artifacts (see subfolder README).

## Notes
- Use `--samples` for quick smoke checks.
- Use a real checkpoint path via `--ckpt` to avoid random-weight outputs.
