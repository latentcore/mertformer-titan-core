# Demo Video Script (Offline, MacBook Air)

## Goal
Show edge-native coding capability without network access, emphasizing privacy and efficiency.

## Outline
1. Intro card: project name and claim (edge-native coding model).
2. System status snapshot (CPU/RAM, device info).
3. Offline prompt demo: run a local prompt set and show outputs.
4. Golden sample run summary.
5. Closing card: asset stack and next steps.

## Step-by-Step
1. Open terminal and run `python scripts/operator_mode_gate.py` in safe mode.
2. Show that the golden sample set is loaded and validated.
3. Run a short local prompt using existing chat or eval script.
4. Show telemetry snapshot output (CPU/RAM/VRAM).
5. End with the asset stack list.

## Timing
- Total length: 3 to 5 minutes.
- On-screen text only; no internet usage.
