# MertFormer Titan: Private Placement Brief

> **Claim boundary:** This pitch is strategic background. It is not a benchmark,
> production, deployment, AGI, or model-superiority claim. Performance and
> mobile wording remain target/estimate until checkpoint-bound evidence exists.

## 💎 The Thesis
Enterprise AI is currently a cloud-dependent OPEX liability. **MertFormer Titan** is a sovereign, 1.58-bit "Edge-Native" SLM direction designed to reduce cloud dependency, cloud inference cost, and external data exposure while pursuing an ambitious low-cost coding-model efficiency target on consumer NPUs.

## ⚡ The Product
A 2.64B design-target coding engine specialized for autonomous software lifecycle management (current build runtime total: ~3.70B).
- **Speed**: Mobile NPU latency remains a target profile until physical-device measurement.
- **Efficiency**: Ternary BitLinear weights target large weight-memory reduction; full runtime memory must be measured per export path.

## 🏰 The Moat
1. **Mathematical Momentum**: Proprietary `LiquidRouter` (causal Conv1d + state buffer) provides temporal, context-aware token routing; CfC dynamics are implemented in `LiquidMixer/LiquidCell`.
2. **Economic Floor**: Lower-cost private inference target for controlled enterprise deployments.
3. **Founder Alpha**: Rapid execution architecture by a systems-focused founder with atypical execution velocity.

## 🚀 Goal
To establish an evidence-backed on-device coding-model validation path under a 3B design-target envelope, then move only measured winners toward production or venture-scale collaboration.
