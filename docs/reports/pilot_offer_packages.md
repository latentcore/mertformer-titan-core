# Pilot Offer Packages

## Starter Pilot (4 Weeks)
- Target: one controlled workflow, one environment
- Includes:
1. Offline verification setup
2. Operator gate execution and report handoff
3. Pilot conclusion memo with go/no-go recommendation

## Security Pilot (6 Weeks)
- Target: compliance-sensitive teams (finance/legal/defense-adjacent)
- Includes:
1. Starter Pilot scope
2. Security + auditability review package
3. Incident runbook walkthrough (`postmortems/_template.md`)

## On-Prem Integration Pilot (8 Weeks)
- Target: enterprise on-prem deployment readiness
- Includes:
1. Security Pilot scope
2. Integration support for customer infra boundaries
3. Acceptance protocol aligned with `reports/poc_protocol.md`

## Standard Deliverables (All Packages)
1. Technical evidence bundle (verify + gate logs)
2. `pilot_report_v1` JSON
3. Pilot findings and recommended next phase
