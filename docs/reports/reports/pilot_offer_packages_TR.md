# Pilot Teklif Paketleri

## Başlangıç Pilotu (4 Hafta)
- Hedef: tek kontrollü iş akışı, tek ortam
- İçerik:
1. Offline doğrulama kurulum paketi
2. Operator gate çalıştırması ve rapor teslimi
3. Pilot kapanış notu ve go/no-go önerisi

## Güvenlik Pilotu (6 Hafta)
- Hedef: uyum hassasiyeti yüksek ekipler (finans/hukuk/savunma komşu alanlar)
- İçerik:
1. Başlangıç Pilotu kapsamı
2. Güvenlik + denetlenebilirlik inceleme paketi
3. Olay runbook walkthrough (`postmortems/_template.md`)

## On-Prem Entegrasyon Pilotu (8 Hafta)
- Hedef: kurumsal on-prem dağıtım hazırlığı
- İçerik:
1. Güvenlik Pilotu kapsamı
2. Müşteri altyapı sınırlarına uygun entegrasyon desteği
3. `reports/poc_protocol.md` ile uyumlu kabul protokolü

## Standart Teslimler (Tüm Paketler)
1. Teknik kanıt paketi (verify + gate logları)
2. `pilot_report_v1` JSON
3. Pilot bulguları ve önerilen sonraki faz
