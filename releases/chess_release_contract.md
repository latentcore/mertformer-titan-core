# Chess Release Contract

A chess onefile run is not release-grade unless all of these exist together:
- trained checkpoint or explicit package-only provenance
- run summary
- model card
- eval card
- feature flag report
- run contract
- release snapshot
- evidence pack stub
- final truth registry
- artifact truth matrix
- run status manifest
- postrun analysis manifest
- artifact manifest with hashes
- final bundle zip and checksum when enabled

Internal self-play and tournament artifacts are diagnostic support, not external release proof by themselves.
