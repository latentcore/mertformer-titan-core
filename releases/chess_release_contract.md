# Chess Release Contract

A chess onefile run is not release-grade unless all of these exist together:
- trained checkpoint or explicit package-only provenance
- run summary
- model card
- eval card
- feature flag report
- run contract
- release snapshot
- evidence pack stub
- final truth registry
- claim registry
- known limits
- support matrix
- release gate summary
- rc stub
- golden stub
- handoff pack manifest
- operator handoff summary
- external repro stub
- pilot stub
- security stub
- legal stub
- operator handbook stub
- dr evidence stub
- backup retention stub
- blind handoff stub
- release notes stub
- freeze manifest stub
- changelog snapshot
- maintenance policy stub
- export truth stub
- device validation stub
- packaging closure stub
- installer validation stub
- benchmark raw outputs stub
- benchmark compare report stub
- benchmark summary stub
- benchmark manifest stub
- training report stub
- token accounting stub
- compute accounting stub
- cost report stub
- artifact truth matrix
- run status manifest
- postrun analysis manifest
- artifact manifest with hashes
- final bundle zip and checksum when enabled

Internal self-play and tournament artifacts are diagnostic support, not external release proof by themselves.
